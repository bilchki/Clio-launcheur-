# Clio Launcher

Interface d'accueil perso pour l'autoradio Android de la Clio III.

Dernière version à installer sur l'autoradio :
`https://github.com/<ton-pseudo>/clio-launcher/releases/latest/download/ClioLauncher.apk`

- Dock : appui court = ouvrir l'appli, appui long = choisir l'appli.
- Maison / Travail : appui long pour enregistrer l'adresse.
- Ma Clio : données OBD2 (adaptateur ELM327 Bluetooth ou Wi-Fi), conso, autonomie, codes défaut, entretien.
- Trajet pro : compte les km d'un déplacement professionnel.
- Réglages (roue dentée) : diagnostic de l'autoradio, test du pop-up porte.
