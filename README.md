# Clio Launcher

## [👉 TÉLÉCHARGER L'APP (ClioLauncher.apk)](https://github.com/bilchki/Clio-launcheur-/releases/latest/download/ClioLauncher.apk)

Interface d'accueil perso pour l'autoradio Android de la Clio III.

- Dock : appui court = ouvrir l'appli, appui long = choisir l'appli.
- Maison / Travail : appui long pour enregistrer l'adresse.
- Ma Clio : données OBD2, conso, autonomie, codes défaut, entretien.
- Roue dentée : diagnostic, démarrage auto, bouton « Mettre à jour ».
